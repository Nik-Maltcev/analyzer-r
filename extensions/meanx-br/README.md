# MEANX Brazil browser extension

Manifest V3 extension for a small public preview of MEANX signals in Brazil.

## Local installation

1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Choose `Load unpacked` and select this directory.

The production API is fixed to `https://www.br.meanx.pro`. The extension requests a
maximum of four read-only signals per market and stores saved signals locally in
Chrome. Full analysis still requires an account in the web service.

## Store checklist

- Use `https://www.br.meanx.pro/privacy/extension` as the Web Store privacy URL.
- Prepare 1280 x 800 screenshots using the copy in the Semrush keyword brief.
- Complete the single-purpose and data-use declarations.
- Zip this directory without development files.
