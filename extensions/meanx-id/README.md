# MEANX Indonesia browser extension

Manifest V3 extension for high-confidence IDX, US stock and crypto signals.

## Local installation

1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Choose `Load unpacked` and select this directory.

The production API is fixed to `https://www.id.meanx.pro`. Saved signals remain
in `chrome.storage.local`; the full terminal opens in a separate tab.

Use `https://www.id.meanx.pro/privacy/extension` as the Chrome Web Store privacy
policy URL.
