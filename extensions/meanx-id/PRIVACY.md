# Kebijakan privasi ekstensi MEANX

Terakhir diperbarui: 11 Juli 2026.

Ekstensi hanya mengakses feed publik terbatas berisi sinyal pasar MEANX. Ekstensi
tidak membaca isi halaman yang dikunjungi, tidak mengumpulkan riwayat penelusuran,
dan tidak meminta data masuk.

Sinyal yang disimpan tetap berada di browser melalui `chrome.storage.local` dan
tidak dikirim ke server oleh ekstensi.

Saat analisis lengkap dibuka, ekstensi membuat tab baru di `www.id.meanx.pro`.
Autentikasi dan penggunaan terminal berlangsung di situs tersebut.
